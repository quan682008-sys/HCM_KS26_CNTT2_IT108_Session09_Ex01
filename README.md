# Phần 1. Phân tích
## 1.Hai sai lầm trong tư duy của Nam
- Sai lầm 1: Nam cho rằng Word tốt hơn Markdown vì có thể chỉnh sửa font chữ và màu sắc. Thực tế, Markdown vẫn có thể tạo tiêu đề, danh sách, bảng, liên kết và chèn ảnh bằng cú pháp đơn giản.
- Sai lầm 2:Nam dùng file Word để lưu trữ tài liệu dự án trên GitHub mà chưa quan tâm đến khả năng so sánh thay đổi. File .docx có cấu trúc nhị phân nên Git khó hiển thị chính xác nội dung được thêm, sửa hoặc xóa. Markdown là văn bản thuần nên Git Diff dễ theo dõi từng dòng thay đổi và hỗ trợ xử lý xung đột tốt hơn.
## 2. Markdown nhẹ hơn vì
- Dung lượng nhẹ
- Dễ khôi phục
- Dễ quản lý
